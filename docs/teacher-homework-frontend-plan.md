# 六年级数学提分系统 · 三模块前端改版方案

配套文档：[教师端作业与学情需求](teacher-homework-pilot-prd.md)

本方案围绕一位老师、四名学生的试点。教师在手机上采集作业，在电脑上核对并形成纸质反馈。学生照常交练习册、订正和复测。

## 1. 一级导航

**教学工作台 · 学生档案 · 母题库**

| 现有入口 | 调整后的去向 |
| --- | --- |
| 今日 | 教学工作台首页，汇总当前批次和接下来要做的事 |
| 录错 | 拍照批改和批量导入并入教学工作台。考试勾题号录错保留为工作台次级入口 |
| 学生 | 学生档案，优先展示近期重复出现的薄弱点 |
| 巩固单 | 从学生档案选题和生成。批量出卷、历史批次和待验收可从工作台进入 |
| 母题库 | 保留独立入口，支持按母题找题和按年份看历年原题 |

保留原有业务入口能完成的操作。第一轮先在现有导航中跑通作业流程，四人试点稳定后再完成一级导航调整。

## 2. 教学工作台

### 首页

首屏只突出当前一批作业和下一步。往下是本批学生清单、待处理事项和近期批次。

> **家庭作业 · 练习册第 40 页**
>
> 已收 4 / 4 人 · 2 题待核对
>
> **核对 2 题**

主按钮随批次状态变化：

- 未开批次时显示「新建作业」。老师选班级、日期、作业名及页码，可关联原题和参考答案。
- 待收件时显示「继续收作业」。可打开手机上传入口，也可以在电脑上传。
- 批改过程中显示「查看进度」。已收到的照片和正在批改的题分别计数。
- 待核对时显示「核对 N 题」。有归属不明的照片时单独提示。
- 确认完成后显示「生成订正清单」。待复核的题回到工作台的待办。

班级清单按学生显示已收页数、批改状态和待处理数量。缺交、待归属、图像需要补拍和笔迹需要核对是不同状态。上传成功后仍可进入其他页面，回来时能看见之前的进度。

### 手机上传

教师使用固定的手机上传页。入口可能带上当前作业批次，打开后显示班级、作业标题和页码。手机端先采用系统相机和相册多选：拍完四本后一次选中并提交。照片中的练习册二维码由后台自动识别学生，拍摄顺序可以打乱。

- 选择照片后显示缩略图和张数，提交前可以删除误选照片。
- 提交后按照片显示「已收」「待确认归属」「上传失败」。已收到的照片进入后台批改，失败的可以单独重试。
- 页面显示已收学生数。识别到两个二维码或没有有效码的照片集中到待归属，同一份作业的多页保留在同一名学生下。
- 老师能从同一入口再次打开当前批次。网页内连续拍摄留待后续试点，学生不参与手机操作。

### 电脑核对页

顶部显示本批次和进度。左侧列出待处理的学生与题号，右侧同时展示该题局部原图、识别出的作答、参考答案、判定和建议错因。点一次「原图」可看整页。

教师可选「确认结果」「改判」「编辑错因」「暂留待确认」。漏识别的题可以从本页已知题号里手动补记。仍看不清时保留原图和待确认状态。确认按钮显示本次会确认几题，暂留的题继续出现在待办。

前端按后端结果提示是识别失败、缺少小问、作答不清，还是批改建议存在分歧。只展示实际取得的证据与状态。局部二次识别如通过实测，可在核对页展示两种读法。页面用同样的核对流程处理两者的差异。

### 订正和复核

从这个批次一键查看或打印各学生的订正清单。清单包含题号和一句可执行的提示，例如「再画一画半圆边界，看看还少算了哪条线」。老师发回练习册时可以口头提醒，也可以打印反馈小条。已确认的错题进入档案。老师改判后，清单同步更新，页面标出需要重新告知学生的条目。

## 3. 学生档案

先给教师一个可行动的结果，再给证据和历史。学生名单可切换，单生页由上到下依次显示：

1. **当前要补的考点。** 默认展示一到两个重点，具体到「半圆周长 · 漏加直径」。注明最近哪几份作业出现过，提供「看原题」和「选同类题」。
2. **实际测验成绩。** 展示基线、最近可比测验和日期。日常作业表现单独呈现。
3. **错题与干预记录。** 展开可看题号、作答证据、具体错因、订正和复测结果。状态包括「待订正」「已订正」「待复测」「本次通过」，允许教师纠正历史判定。

从薄弱点进入母题库时带上考点。老师挑题并生成纸质巩固单。复测后将结果回填到同一条记录，工作台同步更新待办。已有批量巩固单和验收可以继续调用。

## 4. 母题库

- 「按母题找题」保留搜索和考点筛选。详情显示母题讲解、常见错法和关联历年原题，原题可回看出处和附图。
- 「历年真题」支持按年份、原卷和题号浏览。暂待归类的原题仍可查找。
- 教师发布母题后，列表和搜索立即能查到，刷新后也保留。
- 支持从母题库返回原来的学生档案。建作业批次时可复用确切年级、版次、页码或题目对应的参考答案。

## 5. 版式与交互

沿用已确认的极简风格和现有 [页面参考图](../design-reference/overview.png)：暖白底、深墨绿、少量朱砂色、细分隔线。关键状态带短文字，不只靠颜色。大标题用于定方向，主要操作保持明显。异常集中展示，原图和证据在需要时展开。手机使用单列和大点击区。

页面区分加载、空数据、上传失败和待确认，失败后保留已填写的信息。异步批改能继续进行，重新打开页面后恢复当前批次。确认与上传操作防重复提交。

## 6. 交付顺序和验收

1. **首轮**：在现有页面跑通手机多选、自动归属、批次进度、集中核对、纸质订正清单和档案更新。四人试点验证上传和核对，再调整导航。
2. **第二轮**：把「从薄弱点选同类题、出巩固单、记录复测」加到档案，并整合工作台的待复核。
3. **后续**：根据节省教师时间的实测结果，再决定是否加入网页内连续拍摄和局部二次识别。

验收至少走完一次完整课堂场景：老师一次上传四张乱序照片，四名学生归属正确，缺码照片有单独提示。一道争议题可改判，尚未确认的题不进入学情统计。确认后的错题能在学生档案找到并回看原图，生成的纸质订正清单与确认结果一致。随后从档案选同类题并记录复测，确认工作台待办随之更新。
